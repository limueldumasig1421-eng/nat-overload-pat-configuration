# NAT Overload (PAT) - Cisco Packet Tracer

## About
This is my fourth networking project. I configured NAT Overload (PAT) in Cisco Packet Tracer to allow a PC from a private network to communicate with an external server.

## Devices Used
- 2 Cisco 2911 Routers
- 1 Cisco 2960 Switch
- 1 PC
- 1 Server

## What I Did
- Configured the IP addresses of the router interfaces.
- Set up static routes between the networks.
- Created an ACL for the private LAN.
- Configured NAT Overload (PAT) on the main router.
- Tested the connection between the PC and external server.

## What I Learned
I learned how NAT Overload works and how multiple devices can share one public IP address. I also practiced configuring ACLs, static routes, and checking NAT translations.

## Project File
The Packet Tracer file (`nat-overload-pat.pkt`) is included in this repository.
